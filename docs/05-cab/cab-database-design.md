\# YatraIndia – Cab Module Database Design



\## 1. Purpose



This document describes the database design for the YatraIndia Cab Discovery Module.



The module stores cab/service-provider information that can be discovered by customers based on city, state, cab type, name, and availability status.



\## 2. Database



Database name:



yatraindia



The Cab Module uses the existing `yatraindia` database.
